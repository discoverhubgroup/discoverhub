# DiscoverHub社区

> 让好的产品和开源项目被发现

[DiscoverHub](https://discoverhub.cn/) 是一个专注于开源项目和产品的发现与推广社区。社区通过「[分类](https://discoverhub.cn/category/all)」和「[榜单](https://discoverhub.cn/trend/github/rank)」优质的产品和项目聚合，让开发者、开源作者和产品爱好者能够高效地发现、推荐、分享和推广好项目。

通过[发布产品](https://discoverhub.cn/publish)会自动生成详情页,方便用户分享和互动，发布的产品通过社区和Github互动提供日 / 周 / 月榜单，社区会定期通过 GitHub、公众号、知乎、头条等多渠道分发，让优质项目获得持续曝光，让好的项目被更多人发现。

## 社区价值

### 发布项目获得流量？

发布你的开源项目或产品到社区,完善产品信息:填写短标题、推广语、上传推广图片、选择合适分类和标签以及外链,发布第一条评论,生成产品详情页。发布产品成功后会自动分发到社区[产品动态](https://discoverhub.cn/product/all) 以及首页推荐，让你的项目展示给用户。

1. **分类和标签曝光**：项目出现在对应[分类]/[标签](https://discoverhub.cn/category/all),可以通过相关发现
2. **首页推荐**：新发布和热门项目会在首页轮播展示，获得首屏曝光
3. **排行榜**：Star增长快的项目会进入日榜/周榜/月榜，获得二次曝光
4. **GitHub 期刊**：榜单同步发布到 GitHub 日刊、周刊、月刊，被订阅者持续看到
5. **多渠道分发**：优质项目会被推荐到公众号、知乎、头条、交流群等外部渠道
6. **用户互动传播**：评论、点赞、收藏、推荐，每一次互动都会带来新的曝光机会

通过用户互动，实现内容分发。**内容越好，互动越多，曝光越多**。

### 如何发现好项目？

社区提供多种发现方式：

- **关键词检索**：通过关键词:像"deepseek" \ "workbuddy" \ "智能体" \ "openclaw" 等，检索感兴趣的项目
- **[分类标签检索](https://discoverhub.cn/category/all)**：AI智能体、AI工具、AI模型等……按分类标签发现
- **[排行榜](https://discoverhub.cn/trend/github/rank)**：查看日/周/月榜，快速了解项目及产品趋势
- **真实评价**：通过项目和产品评论、评分了解更不同用户使用体验和感受


## 产品流量曝光？

社区的核心机制是让"发现 → 推荐 → 被看见 → 获得关注"形成正向循环：

```
你发现好项目 → 推荐到社区 → 项目获得曝光  →  用户互动(评论、评分、点赞、收藏)
   ↑                                                ↓
项目获得 Star ← 用户评论点赞 ← 更多用户看到  ←  获取更多推荐和展示
```

- **推荐者**：获得社区认可，建立开源影响力
- **项目作者**：获得真实流量和GitHub Star，提升开源项目排名
- **社区用户**：省下筛选时间，能快速了解到好的产品和项目
- **开源生态**：让更多好的产品和项目推荐出来，得到更多贡献者和用户

## 排行榜

我们提供多个维度产品榜单，通过结合Github trending帮你快速了解产品生态趋势：

| 榜单 | 频率 | 入选项目数 | 关注点 |
|------|------|----------|--------|
| [日榜](https://discoverhub.cn/trend/github/rank?type=2) | 每日更新 | Top 10 | 当日 Star 增长最快 |
| [周榜](https://discoverhub.cn/trend/github/rank?type=4) | 每周更新 | Top 20 | 一周内热度攀升最快 |
| [月榜](https://discoverhub.cn/trend/github/rank?type=6) | 每月更新 | Top 30 | 月度最受关注的项目 |

榜单同步发布到 GitHub 期刊，登上榜单的项目会获得来自订阅者的二次流量。

## 你能做什么

- 推荐你发现的好项目和产品
- 浏览首页推荐和最新发布的产品

- 通过产品评价和评论点赞量，寻找适合自己需求的产品

## 为什么加入？

- **发现好的产品**：热爱体验各类产品，挖掘真正实用、被埋没的优质开源项目
- **热衷开源趋势**：洞察开源行业动态与技术趋势，把握前沿技术趋势
- **提升产品影响力**：开源&产品创作者，分享、推荐自己的项目与作品，提升影响力
- **收获真实流量**：面向精准目标用户曝光项目，获取真实曝光与Star增长
- **了解产品反馈**：通过用户互动评论、评分、点赞、收藏等，了解产品使用场景和价值
- **打破马太效应**：助力小众优质项目出圈，摆脱头部项目资源垄断，让好产品不被埋没
