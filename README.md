# DiscoverHub社区

> 让好的产品和开源项目被发现

[DiscoverHub](https://discoverhub.cn/) 是一个专注于开源项目和产品的发现与推广社区。社区通过「[分类](https://discoverhub.cn/category/all)」和「[榜单](https://discoverhub.cn/trend/github/rank)」优质的产品和项目聚合，让开发者、开源作者和产品爱好者能够高效地发现、推荐、分享和推广好项目。

通过[发布产品](https://discoverhub.cn/publish)会自动生成详情页,方便用户分享和互动，发布的产品通过社区和Github互动提供日 / 周 / 月榜单，社区会定期通过 GitHub、公众号、知乎、头条等多渠道分发，让优质项目获得持续曝光，让好的项目被更多人发现。

## 社区价值

### 如何让项目获得流量？

把你的开源项目或产品发布到社区,完善产品信息,会自动分发到社区[产品动态](https://discoverhub.cn/product/all) 以及首页推荐，让你的项目展示给用户。

1. **分类和标签曝光**：项目出现在对应[分类]/[标签](https://discoverhub.cn/category/all),可以通过相关发现
2. **首页推荐**：新发布和热门项目会在首页轮播展示，获得首屏曝光
3. **排行榜**：Star增长快的项目会进入日榜/周榜/月榜，获得二次曝光
4. **GitHub 期刊**：榜单同步发布到 GitHub 日刊、周刊、月刊，被订阅者持续看到
5. **多渠道分发**：优质项目会被推荐到公众号、知乎、头条、交流群等外部渠道
6. **用户互动传播**：评论、点赞、收藏、推荐，每一次互动都会带来新的曝光机会

通过用户互动，实现内容分发。**内容越好，互动越多，曝光越多**。

### 如何发现好项目？

社区提供多种发现方式：

- **关键词检索**：通过关键词:像"deepseek" \ "workbuddy" \ "智能体" \ "openclaw" 等，快速检索感兴趣的项目
- **[分类检索](https://discoverhub.cn/category/all)**：AI智能体、AI工具、AI模型等……按领域精准发现
- **[排行榜](https://discoverhub.cn/trend/github/rank)**：日/周/月榜，快速了解项目趋势以及感兴趣的项目
- **真实评价**：通过评论和评分了解项目价值

### 想分享你发现的好东西？

推荐你发现的好项目或产品，署你的名字，被点赞、被收藏，让你成为社区里的「开源发现者」。

- 推荐项目，附上使用感受
- 写评测，帮其他人做决策
- 评论点赞，让优质评价浮起来
- 你的每一次推荐，都在帮项目获得第一万个 Star

## 流量怎么循环？

社区的核心机制是让"发现 → 推荐 → 被看见 → 获得关注"形成正向循环：

```
你发现好项目 → 推荐到社区 → 项目获得曝光
   ↑                                    ↓
项目获得 Star ← 用户评论点赞 ← 更多用户看到
```

- **推荐者**：获得社区认可，建立开源影响力
- **项目作者**：获得真实流量和 GitHub Star，反哺项目排名
- **社区用户**：省下筛选时间，看到经过评价的优质项目
- **开源生态**：优质项目浮出水面，得到更多贡献者和用户

## 排行榜

我们提供三个维度的榜单，帮你快速了解开源动态：

| 榜单 | 频率 | 入选项目数 | 关注点 |
|------|------|----------|--------|
| [日榜](https://discoverhub.cn/trend/github/rank?type=2) | 每日更新 | Top 10 | 当日 Star 增长最快 |
| [周榜](https://discoverhub.cn/trend/github/rank?type=4) | 每周更新 | Top 20 | 一周内热度攀升最快 |
| [月榜](https://discoverhub.cn/trend/github/rank?type=6) | 每月更新 | Top 30 | 月度最受关注的项目 |

榜单同步发布到 GitHub 期刊，登上榜单的项目会获得来自订阅者的二次流量。

## 你能做什么

- 浏览首页推荐和最新发布
- 按分类和标签发现感兴趣的项目
- 查看产品详情，看实时数据和用户评价
- [发布](https://discoverhub.cn/publish)自己的开源项目或产品
- 推荐你发现的好项目，署名分享
- 收藏、评论、点赞你喜欢的项目
- 订阅开源动态邮件，定期收到精选推荐

## 为什么加入？

- **找工具**：找到真正好用的项目，而不是营销出来的「热门」
- **建影响力**：通过推荐和评论，建立你的开源影响力
- **获流量**：让你的项目被目标用户主动发现，转化为真实 Star
- **看反馈**：通过用户评论，了解项目的真实使用场景
- **破马太**：让优质但小众的项目被看见，避免「富者愈富」
